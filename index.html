RELEASE STATES

What happens after you press Run

01Build

Source validation, package creation, manifest and checksum.

02Intake

Candidate is created in License Master with source and CI metadata.

03Technical approval

License Master scans the package and approves only after validation passes.

04Publication gate

License Manager publishes Base releases. Technically approved Updates go to Billing Store for final customer-facing review and publication.

05Delivery

Published release appears in the customer Base Deployer or Update Deployer.
